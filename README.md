# Shotgun

Лоу-полі фентезійний дробовик для Blender **5.0 або новішого**. Збережено основу початкового приклада та двох паралельних стволів; додано револьверний барабан, латунне обрамлення, дерев’яні й шкіряні матеріали та декоративні вставки за референсами.

## Файли

- `Shotgun.blend` — завершена модель, матеріали, анімація, камери та світло.
- `Shotgun_Animation_Kit/Shotgun_Blockout.blend` — незмінена початкова модель.
- `Shotgun_Animation_Kit/дробовик 1.jpg`, `дробовик 2.jpg`, `дробовик 3.jpg` — вихідні референси. Усі три також упаковані в готовий `.blend`.
- `previews/Shotgun_Hero.png`, `Shotgun_Side.png`, `Shotgun_Detail.png` — загальний вигляд, вид збоку та деталь механізму.
- `previews/Shotgun_Animation.mp4` — відеоперегляд анімації.

Матеріали процедурні: зовнішні файли текстур для відкриття моделі не потрібні.

## Перегляд анімації

Відкрийте `Shotgun.blend` і натисніть **Space** над вікном 3D або таймлайном. Діапазон — **кадри 1–96, 24 кадри/с**: два цикли зведення курка, спуску, віддачі, повороту барабана й руху цівки.

У колекції `RIG | animated controls` є п’ять контролерів для жорстко прив’язаних деталей:

| Контролер | Рух |
| --- | --- |
| `CTRL \| recoil / whole prop` | Увесь предмет і віддача |
| `CTRL \| cylinder` | Поворот барабана |
| `CTRL \| hammer` | Зведення й спуск курка |
| `CTRL \| trigger` | Спусковий гачок |
| `CTRL \| fore-end` | Цівка |

Для перегляду без студійного оточення приховайте колекцію `STUDIO | cameras and lights`. Референси містяться в окремій прихованій колекції `REFERENCES | packed images`.

## Повторне створення

Виконуйте команди з кореня репозиторію у Blender 5.0+. Скрипт бере збережений початковий блокінг і **перезаписує готовий `Shotgun.blend`**; перед ручними змінами збережіть окрему копію готового файлу.

```bash
blender -b --python scripts/finish_shotgun.py
```

Щоб також оновити три зображення перегляду:

```bash
SHOTGUN_RENDER=1 blender -b --python scripts/finish_shotgun.py
```

Рендер анімації з готового файлу:

```bash
blender -b Shotgun.blend --python scripts/render_animation.py
```

Це редагований Blender-асет із простою механічною анімацією. Експорт до ігрового рушія та підготовка UV потребують окремого етапу.
